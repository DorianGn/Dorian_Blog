# 博客系统功能清单（个人博客版）

**项目类型：** 个人博客系统
**创建日期：** 2025-11-21
**技术栈：** .NET 5 + Vue.js + MySQL

---

## 角色定义

- **游客（未登录）**：浏览文章、搜索、查看分类/标签
- **注册用户**：游客权限 + 评论、点赞
- **管理员**：全部权限，发布和管理文章

---

## 一、管理端功能（Admin）

### 1. 文章管理模块

#### 1.1 文章列表
- [ ] 显示所有文章（标题、分类、标签、状态、发布时间、阅读量）
- [ ] 搜索功能（按标题、分类、标签搜索）
- [ ] 筛选功能（按状态、分类、日期范围）
- [ ] 批量操作（批量删除、批量修改状态）
- [ ] 分页显示

#### 1.2 创建/编辑文章
- [ ] 文章标题（必填）
- [ ] 文章封面图片上传
- [ ] 文章摘要（可选，自动提取前200字）
- [ ] 文章内容（富文本编辑器 WangEditor）
- [ ] 选择分类（单选，必填）
- [ ] 选择标签（多选，可新增）
- [ ] 文章状态
  - 草稿（Draft）
  - 已发布（Published）
  - 已隐藏（Hidden）
- [ ] 是否置顶
- [ ] 是否推荐
- [ ] 允许评论（开/关）
- [ ] 保存草稿功能
- [ ] 预览功能

#### 1.3 删除文章
- [ ] 逻辑删除（移入回收站）
- [ ] 回收站管理
- [ ] 永久删除

## 四、技术要点

### 后端（.NET 5）
- Entity Framework Core（ORM）
- JWT 认证（复用现有）
- RESTful API 设计
- 异步编程（async/await）
- 缓存机制（热门文章、分类统计等）
- 日志记录（Serilog）

### 前端（Vue.js）
- Vue 2.x + Ant Design Vue
- WangEditor 富文本编辑器
- Axios HTTP 请求
- Vuex 状态管理
- Vue Router 路由管理
- 响应式布局
- 组件化开发

### 数据库（MySQL）
- 表设计与关联
- 索引优化（标题、内容全文索引）
- 外键约束

## 五、非功能性需求

### 性能要求
- 首页加载时间 < 2秒
- 文章详情页加载时间 < 1秒
- 支持并发访问 100+

### 安全要求
- XSS 攻击防护（富文本内容过滤）
- SQL 注入防护（使用 ORM）
- CSRF 攻击防护
- 评论内容过滤（敏感词、垃圾信息）

### SEO优化
- 友好的 URL 结构
- Meta 标签优化
- 语义化 HTML
- Sitemap 生成（可选）

### 用户体验
- 响应式设计（支持手机、平板、PC）
- 加载动画提示
- 友好的错误提示
- 图片懒加载
