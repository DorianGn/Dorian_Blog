# 文章点赞和评论功能 - 完整实现步骤

## 一、项目架构说明

当前项目采用 N 层架构：

```
前端 (Vue 2 + Ant Design Vue)
        ↓
Controller 层 (Coldairarrow.Api)
        ↓
Business 层 (Coldairarrow.Business + Coldairarrow.IBusiness)
        ↓
Entity 层 (Coldairarrow.Entity)
        ↓
数据库 (EF Core)
```

---

## 二、数据库设计

### 2.1 点赞表 `blog_like`

| 字段名 | 数据类型 | 是否必填 | 说明 |
|--------|----------|----------|------|
| Id | String(50) | 是 | 主键，UUID |
| ArticleId | String(50) | 是 | 文章ID，外键关联 blog_article.Id |
| UserId | String(50) | 是 | 用户ID，外键关联 Base_User.Id |
| CreatedTime | DateTime | 是 | 点赞时间 |

**唯一约束：** `ArticleId + UserId` 组合唯一，防止重复点赞

### 2.2 评论表 `blog_comment`

| 字段名 | 数据类型 | 是否必填 | 说明 |
|--------|----------|----------|------|
| Id | String(50) | 是 | 主键，UUID |
| ArticleId | String(50) | 是 | 文章ID，外键关联 blog_article.Id |
| UserId | String(50) | 是 | 评论用户ID，外键关联 Base_User.Id |
| Content | String(2000) | 是 | 评论内容 |
| ParentId | String(50) | 否 | 父评论ID，用于回复功能，为空表示顶级评论 |
| LikeCount | Int32 | 是 | 评论点赞数，默认0 |
| Status | Int32 | 是 | 评论状态：0=待审核，1=已通过，2=已拒绝 |
| IsDeleted | Int32 | 是 | 软删除标记：0=正常，1=已删除 |
| CreatedTime | DateTime | 是 | 创建时间 |
| CreatorId | String(50) | 否 | 创建人ID |
| UpdatedTime | DateTime | 否 | 更新时间 |
| UpdaterId | String(50) | 否 | 更新人ID |

### 3.4 Business 层 - 实现业务逻辑

#### 步骤 3.4.1：实现点赞业务

**文件路径：** `Coldairarrow.Business/Blog_Manage/blog_likeBusiness.cs`

**实现要点：**
```
blog_likeBusiness : BaseBusiness<blog_like>, Iblog_likeBusiness, ITransientDependency
│
├── ToggleLikeAsync(articleId, userId)
│   ├── 1. 查询是否已存在点赞记录
│   ├── 2. 如果存在 → 删除记录（取消点赞）
│   ├── 3. 如果不存在 → 新增记录（点赞）
│   ├── 4. 更新 blog_article.LikeCount（使用事务）
│   └── 5. 返回当前状态和点赞总数
│
├── IsLikedAsync(articleId, userId)
│   └── 查询点赞记录是否存在
│
├── GetLikeCountAsync(articleId)
│   └── 统计该文章的点赞记录数
│
└── GetLikeListByArticleAsync(articleId)
    └── 返回该文章的所有点赞记录
```

#### 步骤 3.4.2：实现评论业务

**文件路径：** `Coldairarrow.Business/Blog_Manage/blog_commentBusiness.cs`

**实现要点：**
```
blog_commentBusiness : BaseBusiness<blog_comment>, Iblog_commentBusiness, ITransientDependency
│
├── GetDataListAsync(input)
│   ├── 1. 多表 LEFT JOIN 查询（comment + user + article）
│   ├── 2. 应用查询条件（ArticleId, UserId, Status, Keyword）
│   ├── 3. 映射到 Blog_CommentDTO
│   └── 4. 分页返回
│
├── GetCommentsByArticleAsync(articleId)
│   ├── 1. 查询该文章所有评论
│   ├── 2. 构建树形结构（顶级评论 + 子回复）
│   └── 3. 返回评论列表
│
├── AddDataAsync(data)
│   ├── 1. 设置 CreatedTime
│   ├── 2. 插入评论记录
│   └── 3. 更新 blog_article.CommentCount（+1）
│
├── DeleteDataAsync(ids)
│   ├── 1. 软删除评论（设置 IsDeleted = 1）
│   └── 2. 更新 blog_article.CommentCount（-N）
│
└── UpdateStatusAsync(id, status)
    └── 更新评论审核状态
```

## 八、注意事项

### 8.1 安全性考虑

1. **防止重复点赞**：通过 `ArticleId + UserId` 唯一约束保证
2. **评论内容过滤**：对评论内容进行 XSS 过滤，防止恶意脚本注入
3. **权限控制**：
   - 点赞需要登录
   - 评论需要登录
   - 删除评论需要本人或管理员权限
   - 审核评论需要管理员权限

### 8.2 性能优化

1. **点赞数缓存**：可考虑使用 Redis 缓存热门文章的点赞数
2. **评论分页**：评论列表必须分页加载，避免一次性加载过多数据
3. **计数字段**：使用 `blog_article.LikeCount` 和 `CommentCount` 冗余字段，避免每次统计

### 8.3 扩展功能（可选）

1. **评论点赞**：为评论添加点赞功能
2. **评论举报**：添加举报不当评论功能
3. **@提及**：评论中支持 @其他用户
4. **表情支持**：评论支持表情包
5. **评论通知**：被回复时发送通知

using Coldairarrow.Entity.Blog_Manage;
using Coldairarrow.IBusiness.Blog_Manage;
using Coldairarrow.Util;

            return await _blog_categoryBus.GetTheDataAsync(input.id);

            if (data.Id.IsNullOrEmpty())
            {
                InitEntity(data);
                await _blog_categoryBus.AddDataAsync(data);
            }
            else
            {
                await _blog_categoryBus.UpdateDataAsync(data);
            }
        }

        {
            await _blog_categoryBus.DeleteDataAsync(ids);
        }
    }
