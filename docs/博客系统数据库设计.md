# 博客系统数据库设计

**项目名称：** 个人博客系统
**数据库：** MySQL
**字符集：** utf8mb4
**创建日期：** 2025-11-21

---

## 一、数据库表清单

| 表名 | 说明 | 依赖关系 |
|------|------|----------|
| `Blog_Category` | 文章分类表 | - |
| `Blog_Tag` | 文章标签表 | - |
| `Blog_Article` | 文章表 | 依赖 `Blog_Category`、`Base_User` |
| `Blog_ArticleTag` | 文章-标签关联表 | 依赖 `Blog_Article`、`Blog_Tag` |
| `Blog_Comment` | 评论表 | 依赖 `Blog_Article`、`Base_User` |
| `Blog_Like` | 点赞表 | 依赖 `Blog_Article`、`Base_User` |
| `Blog_Banner` | 首页轮播图表 | - |
| `Blog_Setting` | 系统设置表 | - |

**说明：**
- 用户表复用现有的 `Base_User` 表
- 主键统一使用 `Id`（字符串类型，GUID）
- 时间字段统一使用 `DateTime` 类型
- 逻辑删除使用 `IsDeleted` 字段

---

## 二、数据表详细设计

### 1. Blog_Category（文章分类表）

**表说明：** 存储博客文章的分类信息

| 字段名 | 数据类型 | 长度 | 允许NULL | 默认值 | 说明 |
|--------|---------|------|---------|--------|------|
| `Id` | varchar | 50 | NO | - | 主键（GUID） |
| `Name` | varchar | 50 | NO | - | 分类名称 |
| `Description` | varchar | 500 | YES | NULL | 分类描述 |
| `Icon` | varchar | 100 | YES | NULL | 分类图标（图标class或图片URL） |
| `SortIndex` | int | - | NO | 0 | 排序号（越小越靠前） |
| `Status` | tinyint | - | NO | 1 | 状态（0=禁用，1=启用） |
| `ArticleCount` | int | - | NO | 0 | 该分类下的文章数量（冗余字段，提升查询性能） |
| `IsDeleted` | tinyint | - | NO | 0 | 是否删除（0=否，1=是） |
| `CreatedTime` | datetime | - | NO | CURRENT_TIMESTAMP | 创建时间 |
| `CreatorId` | varchar | 50 | YES | NULL | 创建人ID |
| `UpdatedTime` | datetime | - | YES | NULL | 更新时间 |
| `UpdaterId` | varchar | 50 | YES | NULL | 更新人ID |

**索引：**
- PRIMARY KEY (`Id`)
- INDEX `idx_status` (`Status`)
- INDEX `idx_sortindex` (`SortIndex`)

**示例数据：**
```sql
INSERT INTO Blog_Category (Id, Name, Description, Icon, SortIndex, Status) VALUES
('cat001', '技术分享', '技术类文章', 'icon-code', 1, 1),
('cat002', '生活随笔', '生活感悟', 'icon-edit', 2, 1),
('cat003', '学习笔记', '学习心得', 'icon-book', 3, 1);
```

### 2. Blog_Tag（文章标签表）

**表说明：** 存储博客文章的标签信息

| 字段名 | 数据类型 | 长度 | 允许NULL | 默认值 | 说明 |
|--------|---------|------|---------|--------|------|
| `Id` | varchar | 50 | NO | - | 主键（GUID） |
| `Name` | varchar | 50 | NO | - | 标签名称 |

| `ArticleCount` | int | - | NO | 0 | 该标签下的文章数量（冗余字段） |
| `IsDeleted` | tinyint | - | NO | 0 | 是否删除（0=否，1=是） |
| `CreatedTime` | datetime | - | NO | CURRENT_TIMESTAMP | 创建时间 |

```sql
INSERT INTO Blog_Tag (Id, Name, Color) VALUES
```

### 3. Blog_Article（文章表）

**表说明：** 存储博客文章的主体信息

| 字段名 | 数据类型 | 长度 | 允许NULL | 默认值 | 说明 |
|--------|---------|------|---------|--------|------|
| `Id` | varchar | 50 | NO | - | 主键（GUID） |
| `Title` | varchar | 200 | NO | - | 文章标题 |
| `Summary` | varchar | 500 | YES | NULL | 文章摘要 |
| `Content` | longtext | - | NO | - | 文章内容（富文本HTML） |
| `CoverImage` | varchar | 500 | YES | NULL | 封面图片URL |
| `CategoryId` | varchar | 50 | NO | - | 分类ID（外键） |
| `AuthorId` | varchar | 50 | NO | - | 作者ID（外键，关联 Base_User.Id） |
| `Status` | tinyint | - | NO | 0 | 文章状态（0=草稿，1=已发布，2=已隐藏） |
| `IsTop` | tinyint | - | NO | 0 | 是否置顶（0=否，1=是） |
| `IsRecommend` | tinyint | - | NO | 0 | 是否推荐（0=否，1=是） |
| `AllowComment` | tinyint | - | NO | 1 | 是否允许评论（0=否，1=是） |
| `ViewCount` | int | - | NO | 0 | 阅读量 |
| `LikeCount` | int | - | NO | 0 | 点赞数（冗余字段） |
| `CommentCount` | int | - | NO | 0 | 评论数（冗余字段） |
| `PublishTime` | datetime | - | YES | NULL | 发布时间 |
| `IsDeleted` | tinyint | - | NO | 0 | 是否删除（0=否，1=是） |
| `CreatedTime` | datetime | - | NO | CURRENT_TIMESTAMP | 创建时间 |
| `CreatorId` | varchar | 50 | YES | NULL | 创建人ID |
| `UpdatedTime` | datetime | - | YES | NULL | 更新时间 |
| `UpdaterId` | varchar | 50 | YES | NULL | 更新人ID |

**索引：**
- PRIMARY KEY (`Id`)
- INDEX `idx_category` (`CategoryId`)
- INDEX `idx_author` (`AuthorId`)
- INDEX `idx_status` (`Status`)
- INDEX `idx_publishtime` (`PublishTime` DESC)
- INDEX `idx_istop_status` (`IsTop` DESC, `Status`)
- FULLTEXT INDEX `ft_title_content` (`Title`, `Content`) -- 全文搜索索引

**外键约束：**
```sql
FOREIGN KEY (`CategoryId`) REFERENCES `Blog_Category`(`Id`)
FOREIGN KEY (`AuthorId`) REFERENCES `Base_User`(`Id`)
```

**枚举说明：**
- `Status`: 0=草稿（Draft）, 1=已发布（Published）, 2=已隐藏（Hidden）

**示例数据：**
```sql
INSERT INTO Blog_Article (Id, Title, Summary, Content, CategoryId, AuthorId, Status, IsTop, PublishTime) VALUES
('art001', 'Vue.js入门教程', 'Vue.js是一个渐进式JavaScript框架', '<p>文章内容...</p>', 'cat001', 'user001', 1, 1, NOW());
```

### 4. Blog_ArticleTag（文章-标签关联表）

**表说明：** 多对多关联表，一篇文章可以有多个标签，一个标签可以属于多篇文章

| 字段名 | 数据类型 | 长度 | 允许NULL | 默认值 | 说明 |
|--------|---------|------|---------|--------|------|
| `Id` | varchar | 50 | NO | - | 主键（GUID） |
| `ArticleId` | varchar | 50 | NO | - | 文章ID（外键） |
| `TagId` | varchar | 50 | NO | - | 标签ID（外键） |
| `CreatedTime` | datetime | - | NO | CURRENT_TIMESTAMP | 创建时间 |

**索引：**
- PRIMARY KEY (`Id`)
- UNIQUE KEY `uk_article_tag` (`ArticleId`, `TagId`) -- 联合唯一索引
- INDEX `idx_article` (`ArticleId`)
- INDEX `idx_tag` (`TagId`)

**外键约束：**
```sql
FOREIGN KEY (`ArticleId`) REFERENCES `Blog_Article`(`Id`) ON DELETE CASCADE
FOREIGN KEY (`TagId`) REFERENCES `Blog_Tag`(`Id`) ON DELETE CASCADE
```

**示例数据：**
```sql
INSERT INTO Blog_ArticleTag (Id, ArticleId, TagId) VALUES
('at001', 'art001', 'tag001'),
('at002', 'art001', 'tag004');
```

### 5. Blog_Comment（评论表）

**表说明：** 存储文章评论，支持多级回复

| 字段名 | 数据类型 | 长度 | 允许NULL | 默认值 | 说明 |
|--------|---------|------|---------|--------|------|
| `Id` | varchar | 50 | NO | - | 主键（GUID） |
| `ArticleId` | varchar | 50 | NO | - | 文章ID（外键） |
| `UserId` | varchar | 50 | NO | - | 评论用户ID（外键，关联 Base_User.Id） |
| `Content` | text | - | NO | - | 评论内容 |
| `ParentId` | varchar | 50 | YES | NULL | 父评论ID（用于多级回复，NULL表示一级评论） |
| `ReplyToUserId` | varchar | 50 | YES | NULL | 回复的目标用户ID（@用户） |
| `LikeCount` | int | - | NO | 0 | 点赞数 |
| `Status` | tinyint | - | NO | 1 | 状态（0=已删除，1=正常，2=已屏蔽） |
| `IsDeleted` | tinyint | - | NO | 0 | 是否删除（0=否，1=是） |
| `CreatedTime` | datetime | - | NO | CURRENT_TIMESTAMP | 评论时间 |
| `UpdatedTime` | datetime | - | YES | NULL | 更新时间 |

**索引：**
- PRIMARY KEY (`Id`)
- INDEX `idx_article` (`ArticleId`)
- INDEX `idx_user` (`UserId`)
- INDEX `idx_parent` (`ParentId`)
- INDEX `idx_createdtime` (`CreatedTime` DESC)

**外键约束：**
```sql
FOREIGN KEY (`ArticleId`) REFERENCES `Blog_Article`(`Id`) ON DELETE CASCADE
FOREIGN KEY (`UserId`) REFERENCES `Base_User`(`Id`)
FOREIGN KEY (`ParentId`) REFERENCES `Blog_Comment`(`Id`) ON DELETE CASCADE
FOREIGN KEY (`ReplyToUserId`) REFERENCES `Base_User`(`Id`)
```

**数据结构说明：**
- 一级评论：`ParentId` = NULL
- 二级及以上评论：`ParentId` = 父评论的ID
- `ReplyToUserId`：用于标识具体回复的用户（显示 @用户名）

**示例数据：**
```sql
-- 一级评论
INSERT INTO Blog_Comment (Id, ArticleId, UserId, Content, ParentId) VALUES
('cmt001', 'art001', 'user002', '写得很好，学习了！', NULL);

-- 二级评论（回复 cmt001）
INSERT INTO Blog_Comment (Id, ArticleId, UserId, Content, ParentId, ReplyToUserId) VALUES
('cmt002', 'art001', 'user003', '同意，讲解很清晰', 'cmt001', 'user002');
```

### 6. Blog_Like（点赞表）

**表说明：** 记录用户对文章的点赞行为

| 字段名 | 数据类型 | 长度 | 允许NULL | 默认值 | 说明 |
|--------|---------|------|---------|--------|------|
| `Id` | varchar | 50 | NO | - | 主键（GUID） |

**索引：**
- PRIMARY KEY (`Id`)
- UNIQUE KEY `uk_article_user` (`ArticleId`, `UserId`) -- 同一用户只能对同一文章点赞一次

**外键约束：**
```sql
FOREIGN KEY (`ArticleId`) REFERENCES `Blog_Article`(`Id`) ON DELETE CASCADE
FOREIGN KEY (`UserId`) REFERENCES `Base_User`(`Id`) ON DELETE CASCADE
```

**示例数据：**
```sql
INSERT INTO Blog_Like (Id, ArticleId, UserId) VALUES
('like001', 'art001', 'user002'),
('like002', 'art001', 'user003');
```

## 四、SQL建表脚本

### 完整建表语句

```sql
-- ====================================
-- 博客系统数据库初始化脚本
-- 数据库：dorians
-- 字符集：utf8mb4
-- 创建日期：2025-11-21
-- ====================================

USE dorians;

-- 1. 创建分类表
CREATE TABLE IF NOT EXISTS `Blog_Category` (
  `Id` varchar(50) NOT NULL COMMENT '主键',
  `Name` varchar(50) NOT NULL COMMENT '分类名称',
  `Description` varchar(500) DEFAULT NULL COMMENT '分类描述',
  `Icon` varchar(100) DEFAULT NULL COMMENT '分类图标',
  `SortIndex` int NOT NULL DEFAULT 0 COMMENT '排序号',
  `Status` tinyint NOT NULL DEFAULT 1 COMMENT '状态（0=禁用，1=启用）',
  `ArticleCount` int NOT NULL DEFAULT 0 COMMENT '文章数量',
  `IsDeleted` tinyint NOT NULL DEFAULT 0 COMMENT '是否删除',
  `CreatedTime` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `CreatorId` varchar(50) DEFAULT NULL COMMENT '创建人ID',
  `UpdatedTime` datetime DEFAULT NULL COMMENT '更新时间',
  `UpdaterId` varchar(50) DEFAULT NULL COMMENT '更新人ID',
  PRIMARY KEY (`Id`),
  KEY `idx_status` (`Status`),
  KEY `idx_sortindex` (`SortIndex`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='文章分类表';

-- 2. 创建标签表
CREATE TABLE IF NOT EXISTS `Blog_Tag` (
  `Id` varchar(50) NOT NULL COMMENT '主键',
  `Name` varchar(50) NOT NULL COMMENT '标签名称',
  `Color` varchar(20) DEFAULT NULL COMMENT '标签颜色',
  `ArticleCount` int NOT NULL DEFAULT 0 COMMENT '文章数量',
  `IsDeleted` tinyint NOT NULL DEFAULT 0 COMMENT '是否删除',
  `CreatedTime` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `CreatorId` varchar(50) DEFAULT NULL COMMENT '创建人ID',
  `UpdatedTime` datetime DEFAULT NULL COMMENT '更新时间',
  `UpdaterId` varchar(50) DEFAULT NULL COMMENT '更新人ID',
  PRIMARY KEY (`Id`),
  UNIQUE KEY `uk_name` (`Name`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='文章标签表';

-- 3. 创建文章表
CREATE TABLE IF NOT EXISTS `Blog_Article` (
  `Id` varchar(50) NOT NULL COMMENT '主键',
  `Title` varchar(200) NOT NULL COMMENT '文章标题',
  `Summary` varchar(500) DEFAULT NULL COMMENT '文章摘要',
  `Content` longtext NOT NULL COMMENT '文章内容',
  `CoverImage` varchar(500) DEFAULT NULL COMMENT '封面图片',
  `CategoryId` varchar(50) NOT NULL COMMENT '分类ID',
  `AuthorId` varchar(50) NOT NULL COMMENT '作者ID',
  `Status` tinyint NOT NULL DEFAULT 0 COMMENT '状态（0=草稿，1=已发布，2=已隐藏）',
  `IsTop` tinyint NOT NULL DEFAULT 0 COMMENT '是否置顶',
  `IsRecommend` tinyint NOT NULL DEFAULT 0 COMMENT '是否推荐',
  `AllowComment` tinyint NOT NULL DEFAULT 1 COMMENT '是否允许评论',
  `ViewCount` int NOT NULL DEFAULT 0 COMMENT '阅读量',
  `LikeCount` int NOT NULL DEFAULT 0 COMMENT '点赞数',
  `CommentCount` int NOT NULL DEFAULT 0 COMMENT '评论数',
  `PublishTime` datetime DEFAULT NULL COMMENT '发布时间',
  `IsDeleted` tinyint NOT NULL DEFAULT 0 COMMENT '是否删除',
  `CreatedTime` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `CreatorId` varchar(50) DEFAULT NULL COMMENT '创建人ID',
  `UpdatedTime` datetime DEFAULT NULL COMMENT '更新时间',
  `UpdaterId` varchar(50) DEFAULT NULL COMMENT '更新人ID',
  PRIMARY KEY (`Id`),
  KEY `idx_category` (`CategoryId`),
  KEY `idx_author` (`AuthorId`),
  KEY `idx_status` (`Status`),
  KEY `idx_publishtime` (`PublishTime` DESC),
  KEY `idx_istop_status` (`IsTop` DESC, `Status`),
  FULLTEXT KEY `ft_title_content` (`Title`, `Content`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='文章表';

-- 4. 创建文章-标签关联表
CREATE TABLE IF NOT EXISTS `Blog_ArticleTag` (
  `Id` varchar(50) NOT NULL COMMENT '主键',
  `ArticleId` varchar(50) NOT NULL COMMENT '文章ID',
  `TagId` varchar(50) NOT NULL COMMENT '标签ID',
  `CreatedTime` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  PRIMARY KEY (`Id`),
  UNIQUE KEY `uk_article_tag` (`ArticleId`, `TagId`),
  KEY `idx_article` (`ArticleId`),
  KEY `idx_tag` (`TagId`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='文章标签关联表';

-- 5. 创建评论表
CREATE TABLE IF NOT EXISTS `Blog_Comment` (
  `Id` varchar(50) NOT NULL COMMENT '主键',
  `ArticleId` varchar(50) NOT NULL COMMENT '文章ID',
  `UserId` varchar(50) NOT NULL COMMENT '评论用户ID',
  `Content` text NOT NULL COMMENT '评论内容',
  `ParentId` varchar(50) DEFAULT NULL COMMENT '父评论ID',
  `ReplyToUserId` varchar(50) DEFAULT NULL COMMENT '回复的用户ID',
  `LikeCount` int NOT NULL DEFAULT 0 COMMENT '点赞数',
  `Status` tinyint NOT NULL DEFAULT 1 COMMENT '状态（0=已删除，1=正常，2=已屏蔽）',
  `IsDeleted` tinyint NOT NULL DEFAULT 0 COMMENT '是否删除',
  `CreatedTime` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '评论时间',
  `UpdatedTime` datetime DEFAULT NULL COMMENT '更新时间',
  PRIMARY KEY (`Id`),
  KEY `idx_article` (`ArticleId`),
  KEY `idx_user` (`UserId`),
  KEY `idx_parent` (`ParentId`),
  KEY `idx_createdtime` (`CreatedTime` DESC)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='评论表';

-- 6. 创建点赞表
CREATE TABLE IF NOT EXISTS `Blog_Like` (
  `Id` varchar(50) NOT NULL COMMENT '主键',
  `ArticleId` varchar(50) NOT NULL COMMENT '文章ID',
  `UserId` varchar(50) NOT NULL COMMENT '点赞用户ID',
  `CreatedTime` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '点赞时间',
  PRIMARY KEY (`Id`),
  UNIQUE KEY `uk_article_user` (`ArticleId`, `UserId`),
  KEY `idx_article` (`ArticleId`),
  KEY `idx_user` (`UserId`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='点赞表';
```

## 五、查询优化建议

### 1. 常用查询索引优化

```sql
-- 首页文章列表（按置顶+发布时间排序）
SELECT * FROM Blog_Article
WHERE Status = 1 AND IsDeleted = 0
ORDER BY IsTop DESC, PublishTime DESC
LIMIT 0, 10;
-- 使用索引：idx_istop_status, idx_publishtime

-- 分类下的文章列表
SELECT * FROM Blog_Article
WHERE CategoryId = 'xxx' AND Status = 1 AND IsDeleted = 0
ORDER BY PublishTime DESC;
-- 使用索引：idx_category, idx_publishtime

-- 标签下的文章列表
SELECT a.* FROM Blog_Article a
INNER JOIN Blog_ArticleTag at ON a.Id = at.ArticleId
WHERE at.TagId = 'xxx' AND a.Status = 1 AND a.IsDeleted = 0
ORDER BY a.PublishTime DESC;
-- 使用索引：idx_tag, idx_publishtime

-- 全文搜索
SELECT * FROM Blog_Article
WHERE MATCH(Title, Content) AGAINST('关键词' IN NATURAL LANGUAGE MODE)
AND Status = 1 AND IsDeleted = 0;
-- 使用索引：ft_title_content
```

### 2. 冗余字段说明

为提升查询性能，设计了以下冗余字段：

| 表名 | 冗余字段 | 说明 | 更新时机 |
|------|---------|------|---------|
| `Blog_Category` | `ArticleCount` | 分类下的文章数 | 文章新增/删除时更新 |
| `Blog_Tag` | `ArticleCount` | 标签下的文章数 | 文章标签关联/解除时更新 |
| `Blog_Article` | `LikeCount` | 点赞数 | 用户点赞/取消点赞时更新 |
| `Blog_Article` | `CommentCount` | 评论数 | 评论新增/删除时更新 |

### 3. 缓存策略建议

建议对以下数据进行缓存（Redis）：

- **热门文章列表**（按阅读量 TOP 10）- 缓存1小时
- **分类列表** - 缓存24小时
- **标签列表** - 缓存24小时
- **系统设置** - 缓存24小时
- **文章详情** - 缓存10分钟

## 六、数据迁移与维护

### 1. 定期维护任务

```sql
-- 更新分类的文章数量
UPDATE Blog_Category c
SET ArticleCount = (
  SELECT COUNT(*) FROM Blog_Article a
  WHERE a.CategoryId = c.Id AND a.IsDeleted = 0 AND a.Status = 1
);

-- 更新标签的文章数量
UPDATE Blog_Tag t
SET ArticleCount = (
  SELECT COUNT(*) FROM Blog_ArticleTag at
  INNER JOIN Blog_Article a ON at.ArticleId = a.Id
  WHERE at.TagId = t.Id AND a.IsDeleted = 0 AND a.Status = 1
);

-- 更新文章的点赞数
UPDATE Blog_Article a
SET LikeCount = (
  SELECT COUNT(*) FROM Blog_Like l WHERE l.ArticleId = a.Id
);

-- 更新文章的评论数
UPDATE Blog_Article a
SET CommentCount = (
  SELECT COUNT(*) FROM Blog_Comment c
  WHERE c.ArticleId = a.Id AND c.IsDeleted = 0 AND c.Status = 1
);
```

### 2. 数据清理

```sql
-- 清理已删除超过30天的数据
DELETE FROM Blog_Article
WHERE IsDeleted = 1 AND UpdatedTime < DATE_SUB(NOW(), INTERVAL 30 DAY);

DELETE FROM Blog_Comment
WHERE IsDeleted = 1 AND UpdatedTime < DATE_SUB(NOW(), INTERVAL 30 DAY);
```
